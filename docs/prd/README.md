## 1. 产品概述

| 项 | 内容 |
|---|---|
| 产品名 | 结灵子 |
| 一句话 | 练习者的深度交流社区——冥想、正念、太极、站桩、瑜伽等身心练习的同好，在这里慢慢聊、认真记录 |
| 定性 | 个人成长与传统文化交流社区（**非**互联网宗教信息服务） |
| 平台 | 微信小程序 + React Native App（iOS / Android），共用一套 Taro 代码与 CloudBase 后端 |
| 上线主体 | 企业账号 |
| 商业模式 | MVP 免费；后续仅考虑会员费。无广告、无打赏、无募捐 |

**要解决的问题**：练习者的交流散落在微信群里，信息浅、杂、刷屏快，有价值的经验沉不下来；想认真交流的人找不到彼此。

**产品原则**：

1. **深度优先**：长文优于短句，质量优于数量（短回复折叠、每日发帖上限、慢话题）。
2. **反算法**：不做推荐流、不追停留时长；内容按时间与精华组织。
3. **安全克制**：邀请制圈子、后台实名、内容先审后发，宁可慢不可乱。
4. **温和**：通知只与"我"直接相关，不推送营销与热点。

**竞品对照**

| 产品 | 长处 | 结灵子的差异 |
|---|---|---|
| 微信群 | 熟人、即时 | 结构化话题、可沉淀、可检索 |
| 冥想类 App（潮汐、Now 正念等） | 工具与内容完整 | 不做内容库，做"人与人"的交流 |
| 豆瓣小组 / 即刻 | 兴趣社区成熟 | 邀请制 + 慢社交，规模小而深 |
| 知识星球 | 付费社群 | 无"老师-学员"结构，不收费，避免个人崇拜 |

## 2. 品牌与 Logo

![logo](./assets/logo.png)

- **图形**：一笔连成的"结"（∞ 形双环）＋ 上方一粒"子"（种子 / 一点觉察）。双环代表人与人的连结、练习的循环往复；种子代表每个人内在的成长。不使用莲花、太极图、圆相等宗教符号。
- **色彩**

| 名称 | 色值 | 用途 |
|---|---|---|
| 竹青（主色） | `#578A6B` | Logo、主按钮、强调 |
| 宣纸（背景） | `#F7F8F2` | 页面背景 |
| 墨（正文） | `#2F3A33` | 正文文字 |
| 淡墨（辅助） | `#8A948D` | 次要文字、分隔 |
| 朱砂（警示） | `#C2553F` | 错误、举报、删除（少量使用） |

- **字体**：系统默认字体；标题可选思源宋体（按需加载，`TARO_APP_FONT_BASE_URL`）。
- **调性**：安静、留白、纸感；动效轻缓（≤ 300ms），无弹跳、无闪烁。
- **待办**：当前 Logo 图形在画布中偏小，出 App 图标前需放大至占画布约 60%，并输出矢量稿（SVG）、小程序头像、各尺寸 App 图标（`scripts/gen-icons`）、启动页。

## 3. 合规红线（所有需求的前置约束）

| # | 红线 | 产品落地 |
|---|---|---|
| C1 | 不传播宗教教义、不组织宗教活动 | 全站措辞只用"练习"；不设宗教名称分类；关键词库拦截 |
| C2 | 禁止疗效承诺、劝停药、发功/加持等服务 | 社区公约明文禁止；机审词库 + 人工复审 |
| C3 | 不募捐、不打赏 | 无任何资金流转功能（MVP 不收费） |
| C4 | 后台实名 | 发布内容前必须绑定手机号；前台可匿名展示 |
| C5 | 仅限 18+ | 首次进入年龄确认；协议写明 |
| C6 | 防邪教、诈骗、精神控制 | MVP 不做私聊；禁止站外引流（二维码、微信号机审）；举报闭环 |
| C7 | 不做"导师认证" | 只设"资深练习者"贡献标识，不代表平台背书，不得收费 |

**措辞规范**：用"练习 / 练习方式 / 练习记录 / 同好 / 共练"；不用"修行 / 法门 / 同修 / 师父 / 加持 / 开示"等。完整词表见 `docs/prd/wording.md`（M0 产出）。

## 8. 数据模型

> CloudBase 文档数据库。**所有写操作经云函数**（`user` / `community` / `moderation` / `practice`），安全规则默认"仅云函数写"。时间字段统一为毫秒时间戳。

### 8.1 集合与字段

**`users`**（已有，扩展）

| 字段 | 类型 | 说明 |
|---|---|---|
| `_id` | string | uid |
| `phoneHash` | string | 手机号哈希（加盐），用于唯一性校验，不存明文 |
| `phoneVerified` | bool | 是否已实名 |
| `adultConfirmedAt` | number | 18+ 确认时间 |
| `consentVersion` | string | 已同意的协议版本 |
| `role` | `user` / `mod` / `admin` | 角色，仅脚本可改 |
| `bannedUntil` / `mutedUntil` | number | 封禁 / 禁言截止 |
| `inviteQuota` | number | 剩余邀请名额 |
| `createdAt` / `updatedAt` | number | |

**`profiles`**：`uid`(唯一)、`nickname`(2–16)、`avatar`(云存储 fileID)、`practices`(string[]，预置值)、`years`(number)、`goal`(≤ 40)、`bio`(≤ 80)、`anonAlias`(唯一，如"竹影")、`badges`(string[]，如 `senior`)、`updatedAt`。

**`circles`**：`name`、`desc`、`cover`、`rules`(圈子公约)、`memberCount`、`topicCount`、`sort`、`status`。

**`memberships`**：`circleId`、`uid`、`joinedAt`、`invitedBy`、`role`(`member`，预留 `owner`)。唯一索引 `(circleId, uid)`。

**`invites`**：`code`(8 位，唯一)、`circleId`、`ownerUid`、`usedBy`、`usedAt`、`expiresAt`。

**`topics`**

| 字段 | 类型 | 说明 |
|---|---|---|
| `circleId` | string | |
| `authorUid` | string | **永不下发前端** |
| `anon` | bool | 匿名发布 |
| `title` / `body` | string | 5–40 / ≥ 50 字 |
| `tags` | string[] | ≤ 3 |
| `images` | string[] | ≤ 4（fileID） |
| `slowUntil` | number | 慢话题开放时间（P1） |
| `status` | `pending` / `ok` / `folded` / `removed` | 机审与举报状态 |
| `featured` | bool | 精华 |
| `replyCount` / `reportCount` | number | |
| `createdAt` / `lastReplyAt` | number | |

**`replies`**：`topicId`、`circleId`、`authorUid`、`anon`、`body`、`short`(< 30 字)、`quoteId`、`status`、`reportCount`、`createdAt`。

**`reports`**：`targetType`(`topic`/`reply`/`user`)、`targetId`、`reporterUid`、`reason`、`note`、`state`(`open`/`resolved`)、`result`、`handledBy`、`handledAt`。唯一索引 `(targetId, reporterUid)`。

**`checkins`**：`uid`、`date`(`YYYY-MM-DD`，用户本地时区)、`minutes`、`practice`、`note`。唯一索引 `(uid, date, practice)`。

**`daily_prompts`**：`date`(唯一)、`question`。**`prompt_answers`**：`promptId`、`uid`、`anon`、`body`、`status`。唯一索引 `(promptId, uid)`。

**`notifications`**：`uid`、`type`(`reply`/`moderation`/`prompt`)、`refId`、`text`、`read`、`createdAt`。

**`rate_limits`**：`key`(`uid:action:date`)、`count`、`expireAt`（TTL 清理）。

### 8.2 关系

```
users 1─1 profiles
users 1─n memberships n─1 circles
circles 1─n topics 1─n replies
users 1─n invites (owner) ; invites 0..1─1 users (usedBy)
topics/replies/users 1─n reports
users 1─n checkins ; daily_prompts 1─n prompt_answers
```

### 8.3 规则

- **匿名脱敏**：接口返回 `author: { name, avatar, badges, isSelf }`，匿名时 `name = anonAlias`、`avatar` 为默认图；任何接口不返回 `authorUid`。
- **注销**：删除 users、profiles、memberships、invites（未使用）、checkins、notifications；已发布的话题/回复保留但作者显示为"已注销用户"（用户协议中说明）。登记到 `_shared` 的账号数据登记表。
- **合并**：以主账号为准迁移 memberships、topics/replies 的 `authorUid`、checkins（同日累加）。

## 9. 非功能需求

| 类别 | 要求 |
|---|---|
| **性能** | 首页话题流首屏 < 1.5s（4G）；话题详情 < 1s；云函数 P95 < 800ms；小程序主包 < 2MB，总包 < 20MB；RN 冷启动 < 3s（中端安卓） |
| **可用性** | 弱网可浏览已加载内容；草稿本地自动保存；计时器在切后台/锁屏后按时间戳恢复 |
| **安全** | 所有写接口经统一检查链路（登录 → 实名 → 18+ → 未封禁 → 频控 → 机审）；越权校验（圈子成员、作者本人、管理员）；手机号仅存哈希；密钥只在云函数环境变量与 `.env`（已 gitignore）中，前端只用 Publishable Key |
| **隐私** | 遵循个人信息保护法：最小必要收集；隐私政策列出 SDK 清单（`docs/ops/app-sdk-list.md`）；提供注销与数据删除；同意前不初始化统计/第三方 SDK |
| **内容安全** | 文本发布同步机审，图片异步机审；举报 24h 内处理；机审日志保留 6 个月；违规内容与处罚记录保留以备监管查询 |
| **兼容性** | 微信基础库 ≥ 2.30；iOS ≥ 13；Android ≥ 7.0（API 24）；适配深色模式（P1）与大字体 |
| **可访问性** | 文字对比度 ≥ 4.5:1；点击区域 ≥ 44pt；不依赖颜色传达唯一信息 |
| **可观测性** | 云函数错误日志与告警；关键行为埋点（只记录事件，不记录内容正文）；指标看板对应 §11 |
| **可维护性** | TypeScript 严格类型；前端 jest、云函数 `node --test` 覆盖新增逻辑；接口契约在 `docs/api/`；三端代码差异只放在 `.weapp.ts` / `.rn.ts` 平台文件里 |
| **数据** | 每日自动备份（`docs/ops/backup.md`）；单一 CloudBase 环境（开发与生产共用，见 agent 约定），测试数据以 `test_` 前缀区分并定期清理 |
