# 措辞规范（PM-M0-01）

> 依据：PRD §3 合规红线 C1 / C2。适用范围：界面文案、推送 / 订阅消息、协议、种子数据、运营文案、应用商店描述。
> 自动检查：`src/constants/__tests__/community.test.ts` 扫描 `src/` 界面文案中的禁用词（`BANNED_UI_WORDS`）。
> 用户发布内容不强制改写，但命中下表"内容拦截"一列的词会进入机审复核（M2 词库）。

## 1. 基本原则

- 只说"练习"，不说"修"；只说"同好"，不说"同修"；只讲个人体验，不讲教义与神通。
- 不出现任何宗教名称作为分类、圈子名、标签预设。
- 不做疗效、功效、"治愈"承诺。

## 2. 替换表（界面与运营文案）

| 不用 | 改用 |
|---|---|
| 修行、修炼、修持 | 练习 |
| 法门、功法（作为分类） | 练习方式 |
| 同修、道友、师兄 | 同好、练习者 |
| 师父、上师、老师（平台认证意义上） | 资深练习者（贡献标识） |
| 开示、讲法、传法 | 分享、经验 |
| 共修、法会 | 共练、一起练习 |
| 打坐（可用，但分类名优先） | 静坐 / 冥想 |
| 禅修营、闭关 | 静修营（仅线下合作方名称原样保留） |
| 修行日记 | 练习记录 |
| 功德、福报、业力 | （不用） |
| 加持、灌顶、皈依、供养、开光 | （不用；内容中出现进入复核） |

## 3. 内容机审重点（M2 词库的初始分类）

| 分类 | 示例 | 处理 |
|---|---|---|
| 宗教活动组织 | 皈依、灌顶、法会报名、开光 | 复核 |
| 疗效 / 医疗 | 治愈、根治、停药、包好、排毒、发功治病 | 拒绝或复核 |
| 神秘能力 | 开天眼、通灵、隔空、预言 | 复核 |
| 资金 | 随喜、捐款、转账、收徒费 | 复核 |
| 站外引流 | 微信号、二维码、QQ 群、手机号 | 拒绝（M2 正则） |
| 邪教 / 违法组织 | 按监管名单维护 | 拒绝并上报 |

## 4. 练习方式预置列表

见 `cloudfunctions/_shared/config.js` 的 `PRACTICES`（前端同步 `src/constants/community.ts`）：
冥想、正念、内观、太极、站桩、传统养生功法、瑜伽、呼吸练习、书法静心、茶道静心、经典阅读、其他。

## 5. 官方圈子（待确认；M4 种子数据按本节，`slug` 固定、名称可改）

| slug | 圈子 | 简介（≤ 60 字） | 圈子公约草稿（≤ 5 条，每条 ≤ 60 字；在全站公约 `community-rules.md` 之上补充） |
|---|---|---|---|
| `mindful` | 静观练习 | 冥想、正念、内观的日常练习与困惑 | 1. 说具体：做法、时长、当时的感受，少下结论。 2. 讲方法时先说明这是个人经验，不替别人定「应该」。 3. 不评判他人的练习方式。 |
| `tradition` | 传统养生 | 太极、站桩、传统养生功法的身体经验 | 1. 只谈自己的身体体验，不做诊断，不承诺疗效。 2. 不劝任何人停药或放弃就医。 3. 不推销课程、器具与药品。 |
| `lifestyle` | 正念生活 | 把练习带进工作、家庭与日常 | 1. 说真实的日常场景，而不是道理。 2. 提到他人时不透露能识别身份的信息。 3. 遇到心理或健康方面的困难，请同时寻求专业帮助。 |

约束：圈子名、简介、公约都过 `wording.md` §2 禁用词表；名称不得含宗教名称（§1）。官方圈子的最终名称与公约仍是 PRD §12 待确认项；改名只需修改 `scripts/ops/circles.seed.json` 后重跑 `circles.mjs seed`（见 `m4-plan.md` §8），不影响成员与话题。
