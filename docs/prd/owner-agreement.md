# 圈主协议（骨架 · 草案）

> 状态：**骨架草案（2026-10-03），未定稿、未经法务审阅**；属 v0.3「用户自建圈子」的前置交付物（见 [`join-plan.md`](./join-plan.md) §2 D-J8）。
> 说明：v0.3 上线自建圈子时，圈主须完成实名、签署本协议并经官方开通；正式版本在送审前须比照 [`wording.md`](./wording.md) §1 / §2 与 [`community-rules.md`](./community-rules.md) 的流程走措辞检查与法务审阅。

## 一、成为圈主

1. 年满 18 周岁、已完成后台实名的注册用户；
2. 由官方邀请 / 审批开通，并签署本协议（版本号记录在账号上）；
3. 圈主身份不收费、不可转让；官方保留暂停与收回的权利。

## 二、圈主的职责

1. **维护氛围**：对照全站公约与圈子公约，处理圈内内容举报与入圈申请；
2. **认真审核**：只按公开的审核标准（[`join-plan.md`](./join-plan.md) §4）处理申请，不评价他人的练习水平与身份；
3. **及时响应**：举报与申请在 24 小时内处理；长期不活跃（如 28 天没有任何管理或参与记录）时，圈子可能被评估、合并或关闭；
4. **留痕与透明**：所有管理动作由平台记录操作日志；圈子规则应向成员公开说明。

## 三、红线（违反即收回圈子；构成严重违规的按社区公约处理，直至封禁）

1. 不得以圈子名义或利用圈子募捐、收费、卖课、收徒、推销任何商品或服务（含变相形式：赞赏、会员群、导流到站外）；
2. 不得组织或招募宗教活动、传播宗教教义、宣扬个人崇拜、神化自己；
3. 不得泄露成员信息（申请表单内容、匿名身份、举报人）；
4. 不得利用管理权打击异己、排挤成员或进行任何形式的报复；
5. 不得将圈子用于医疗、疗效相关的诊断与承诺；遇到成员的健康与心理问题，引导其寻求专业帮助。

## 四、平台的权利与义务

1. 平台依法对圈内内容进行审核与抽查（机器审核全覆盖；人工抽查与举报处理不因圈子是否私密而豁免），并保留在必要时收回 / 合并 / 关闭圈子的权利（`circles.status: closed`）；
2. 平台处理重大违规时，可依法上报并保留相关记录（日志留存 ≥ 6 个月）；
3. 平台为圈主提供管理工具与操作留痕；不提供成员个人信息的导出能力。

## 五、成员数据

1. 申请表单信息仅用于入圈审核与圈子管理，按最小化原则收集（见 [`join-plan.md`](./join-plan.md) §4），被拒申请定期清理；
2. 圈主可见的成员信息以产品实际提供的范围为准；不得另建台账、不得导出、不得站外使用。

## 六、违约与终止

1. 处理流程：提醒 → 限期整改 → 收回圈子权限 → 按社区公约处罚（严重者封禁）；处理结果站内通知，可申诉（沿用社区公约 §四的申诉通道）；
2. 圈主主动请辞：提前指定交接，或由平台评估合并 / 关闭；
3. 本协议与全站公约、用户协议冲突时，以后者为准。
