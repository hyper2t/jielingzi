# 结灵子社区公约（初稿 · PM-M0-01）

> 首次发布前强制阅读一次（FE-M2-03）；版本号写入 `users.consentVersion`。本文为初稿，上线前需法务审阅。
> 版本：v0.1（2026-10）

结灵子是练习者的深度交流社区。我们希望这里安静、真诚、有温度。请和我们一起守护它。

## 一、我们鼓励

1. **分享真实的练习体验**：你做了什么、感受到什么、遇到了什么困难。
2. **认真回应**：读完再回，说出你的经验，而不只是"赞同""+1"。
3. **尊重差异**：每个人的练习方式和节奏不同，不评判、不说教。
4. **保护彼此**：匿名是为了让人放心表达，请不要试图打探他人身份。

## 二、不允许

1. **宗教活动**：传播宗教教义、组织或招募宗教活动（如皈依、灌顶、法会）、宣扬个人崇拜。
2. **医疗与疗效承诺**：声称练习可以治疗疾病、劝人停药或放弃就医、提供"发功""加持"等服务。练习不能代替医疗。
3. **金钱往来**：募捐、收费授课、收徒、推销课程或产品、任何形式的转账请求。
4. **站外引流**：发布微信号、二维码、群号、手机号等联系方式，或引导到其他平台。
5. **违法与有害信息**：违反法律法规、宣扬邪教或迷信、色情、暴力、赌博、诈骗。
6. **伤害他人**：人身攻击、骚扰、歧视、泄露他人隐私、冒充他人。
7. **低质刷屏**：重复发布、无意义内容、广告。

## 三、未成年人

结灵子仅面向年满 18 周岁的用户。

## 四、处理方式

| 情形 | 处理 |
|---|---|
| 机审命中 | 内容不予发布或进入人工复核 |
| 被多人举报 | 内容自动折叠，等待人工复核 |
| 确认违规（轻微） | 删除内容 + 站内通知 |
| 多次违规 / 情节较重 | 禁言 1–30 天 |
| 严重违规（违法、诈骗、宗教活动组织、医疗欺诈等） | 永久封禁，必要时依法上报 |

处理结果会通过站内消息告知。对处理有异议，可在"设置 → 反馈"中申诉（v0.2）。

## 五、内容与账号

- 你发布的内容由你负责；平台依法留存发布记录。
- 注销账号后，你的档案、打卡等个人数据会被删除；已发布的话题与回复将保留并显示为"已注销用户"，如需删除请在注销前自行删除。
- 匿名发布仅对其他用户匿名，平台后台实名（手机号）。
