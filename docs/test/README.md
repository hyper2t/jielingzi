# 结灵子 MVP 测试计划（QA-M0-01）

> 需求：`docs/prd/README.md`；任务：`docs/prd/mvp-plan.md`；用例：`docs/test/cases/<里程碑>.md`（模板见 `cases/_template.md`）。

## 1. 范围与策略

| 层 | 工具 | 命令 | 谁写 |
|---|---|---|---|
| 云函数单测 | `node --test` + `tests/cloudfunctions/fakeDb.js` | `yarn test:functions` | BE（QA 评审分支覆盖） |
| 运维脚本 | `node --test` | `yarn test:ops`（需 Node ≥ 22.6，类型剥离） | OPS |
| 前端单测 / 快照 | jest + react-test-renderer | `yarn test` | FE |
| 类型 | tsc | `npx tsc --noEmit` | FE |
| 三端手工 / 真机 | 微信开发者工具 + 真机；iOS / Android 真机 | 按 `cases/*.md` | QA |
| 专项 | 抓包（匿名泄露、越权）、弱网、措辞扫描 | 见 §4 | QA |

**每个里程碑的出口**：自动化全绿 + 该里程碑用例三端执行通过 + 无 P0/P1 遗留。里程碑结束后 2 个工作日内完成执行并在用例文件里记录结果。

## 2. 环境与数据

- **单一 CloudBase 环境**（开发与生产共用，见 agent 约定）：测试数据一律带 `test_` 前缀（昵称、话题标题、圈子名），每个里程碑结束后清理。
- 数据源：本地开发默认 `TARO_APP_DATA_SOURCE=mock`；联调与真机用 `cloud`。
- 管理员账号：`scripts/ops/set-role.mjs`（M2）设置 `users.role`。

## 4. 专项清单

1. **匿名不泄露**：抓包检查所有返回体不含 `authorUid` / `_openid` / 手机号（M3 起每个里程碑回归）。
2. **越权**：非成员读圈内话题、非作者删内容、非管理员调用审核动作。
3. **额度与频控**：边界（第 N 次成功、第 N+1 次 42901）、北京时间零点切日、被机审拒绝不扣额度。
4. **措辞**：jest 自动扫描 `src/`；种子数据与协议人工核对 `docs/prd/wording.md`。
5. **注销**：档案 / 打卡删除；话题 / 回复显示"已注销用户"；再登录为新账号。
6. **弱网与离线**：已加载内容可读；草稿不丢；计时器切后台恢复。

## 5. 缺陷分级

| 级别 | 定义 | 时效 |
|---|---|---|
| P0 | 合规风险（违规内容漏放、匿名泄露、越权）、崩溃、无法登录 | 当天修复 |
| P1 | 核心流程阻断（发布 / 回复 / 入圈失败） | 2 天 |
| P2 | 功能异常有替代路径、文案错误 | 本里程碑内 |
| P3 | 体验 / 视觉 | 排期 |
